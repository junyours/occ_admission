# Design & implementation plans

Store **reviewable plans** here before large UI or feature work.

## How to use

1. Copy `templates/ui-redesign-plan.md` to a new file, e.g. `2026-05-18-guidance-dashboard-redesign.md`.
2. Fill in audit and proposed layout.
3. Share with the user; wait for **go** before implementing.
4. After shipping, optionally add a one-line "Done" note at the top of the plan file.

## Templates

| Template | Purpose |
|----------|---------|
| `templates/ui-redesign-plan.md` | Page/dashboard declutter and layout |

Agents: prefer plans over jumping straight into 400-line JSX rewrites.
